# Product Context

## Product Purpose
Hakoot is an interactive learning platform designed to make education engaging and effective. It allows educators to create custom quizzes with various question types, host live interactive sessions, and track student progress in real-time. Unlike traditional quiz platforms, Hakoot focuses on actual learning outcomes with features like code blocks, markdown content, and detailed explanations.

## Users
- **Primary:** Teachers, instructors, and educators who want to create engaging learning experiences
- **Secondary:** Students and learners who participate in interactive quiz sessions
- **Tertiary:** Corporate trainers and workshop facilitators

## Register
product

## Brand Tone
- Energetic and engaging without being childish
- Educational but not stuffy or academic
- Arcade/retro gaming aesthetic with modern polish
- Confident and direct - "actually learn something" positioning
- Technical competence meets playful design

## Anti-References
- Generic SaaS dashboards with bland blue/gray palettes
- Overly corporate educational platforms
- Childish cartoon aesthetics (we're not for elementary school)
- Kahoot's exact visual language (we're inspired by, not copying)

## Strategic Principles
1. **Learning First:** Every design decision should support actual learning, not just engagement metrics
2. **Instant Clarity:** Users should understand what to do within 2 seconds of seeing any screen
3. **Arcade Energy:** Borrow from arcade games - bold colors, clear feedback, satisfying interactions
4. **Progressive Disclosure:** Show complexity only when needed
5. **Real-time Feel:** Everything should feel live and responsive
